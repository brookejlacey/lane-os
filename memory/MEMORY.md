# Memory (index)

Loaded each session as a table of contents. A rule names its own file on its line,
wherever that rule loads (`global/CLAUDE.md`, the spine's `CLAUDE.md`, the lane lines in
`hooks/session-start.sh`, a desk's `CLAUDE.md`), so those files are not listed again here.
This index lists the rest, one line each; detail lives in the file (see `README.md`).
