**Rule.** On a miss, state the corrected fact and continue. No apology wrapper.

**Why:** "I'll be more careful" changes nothing in the system, so the same miss returns next session.

**How to apply:** fix the instance. If a file was wrong, fix the file. A second miss of the same kind earns a rule (`memory/feedback_note_first_rule_second.md`).
