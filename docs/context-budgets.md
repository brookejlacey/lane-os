# Byte budgets on context files

Four files load into every session before it is asked anything: the constitution, the
memory index, `brain/ACTIVE_NOW.md` and `brain/CONCERNS.md`. Each had a written brevity
rule. Measured over four months, the two with a byte ceiling were flat or smaller; the
two governed by prose alone had grown 2x and 5.2x, and startup load had gone from 31k to
81k characters, about 20,000 tokens paid by every lane on every start.

The failure was never carelessness. It was an ungated rule. So every file a session
reads whole now carries a budget, and every budget lives in one table.

## One table, every consumer

`scripts/check-file-budgets.py` holds the table. `audit-cheap.sh` Check 4 calls it at
commit time. Any scheduled job you run points at the same script. A second copy of the
thresholds anywhere is how two gates drift apart.

```bash
python3 scripts/check-file-budgets.py              # every tracked file
python3 scripts/check-file-budgets.py --over-only  # findings only
python3 scripts/check-file-budgets.py --json       # for a job
# exit 0 clean, 1 a warn, 2 a hard ceiling
```

Characters, not bytes: a budget about context cost is about characters.

## Threshold policy

A check that fails the next unrelated commit gets disabled, not obeyed. So `fail` exists
only for the files that load into every session. Everything else is warn-only, because
which file needs an archival pass, and what in it is still current, is lane judgment. Set
a new threshold above today's legitimate reading, so the check catches a runaway rather
than nagging about a file that is merely large on purpose.

Two budgets are deliberately generous for the same reason: nothing in the file goes
stale by date. A lane's `MEMORY.md` is dense durable fact with no history to archive, and
`brain/DECISIONS.md` is never pruned by age because an old decision still binds.

## Code repos too

A code lane's own instruction files are read at the start of every session there, so
they carry budgets from the same table: `CLAUDE.md` holds mechanism only (commands,
gotchas, hard rules), `BACKLOG.md` is the queue, and `DECISIONS.md` keeps a
`## Archive` divider with only the half above it budgeted, because that is all a session
reads. `AGENTS.md` is generated by the rules sync and is deliberately not budgeted; its
size is the constitution's problem, gated there.

## How to apply

- Adding to one of the four means removing from it in the same edit, once past warn.
- Depth out of `ACTIVE_NOW` goes to the lane's `STATUS.md`.
- Resolved concerns go to `brain/archive/` with their evidence, never re-dated in place.
- Move history to an archive file verbatim. Never delete it to satisfy a number.

`scripts/tests-file-budgets.py` asserts the gate blocks at each level, ignores
`_TEMPLATE` files, reports an aliased lane once under its canonical path, and charges
`DECISIONS.md` only above the divider.
